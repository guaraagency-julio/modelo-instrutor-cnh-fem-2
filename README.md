# Modelo de instrutora de direção — Feminino 2

Projeto demonstrativo de landing page da Guará Agency para instrutoras de direção.

> A marca, a profissional e as promessas operacionais são demonstrativas; substituir pelas informações confirmadas antes de vender/publicar para uma cliente.

- Site estático em HTML, CSS e JavaScript, sem dependências de runtime.
- Publicação pelo GitHub Pages via GitHub Actions.
- WhatsApp configurável em `script.js`.
- Direção prioritária: mulheres habilitadas que desejam voltar a dirigir com acompanhamento de outra mulher.

Projeto da Guará Agency.
